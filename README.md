# Phrasal Path · 200 фразовых глаголов

[Открыть приложение](https://evgk724.github.io/phrasal-path/) · [QR-код](https://evgk724.github.io/phrasal-path/assets/install-qr.png)

200 полезных многословных глаголов для перехода от B1 к B2: смысловые опоры для памяти, порядок слов, типичные ошибки русскоговорящих и 400 записей Microsoft Ryan. Крупный текст, тренировки по смыслу, в контексте и на слух.

## Установка и работа без сети

Откройте ссылку в Safari, выберите «Поделиться» → «На экран Домой». Запустите установленное приложение при включённом интернете и дождитесь «Готово без интернета». Весь набор и вся озвучка сохраняются заранее. Очистка данных браузера потребует повторной загрузки.

Прогресс, избранное и личные примеры хранятся в этом браузере на этом устройстве. Резервная копия и восстановление доступны в разделе «Память». Пользовательские примеры не отправляются на сервер.

## Учебный подход

Одна карточка — одно полезное значение и два оригинальных примера. Смысловая ассоциация помогает вспомнить выражение, но не служит универсальным правилом перевода частиц. Грамматика относится к выбранному значению: другой смысл того же глагола может иметь другую конструкцию.

200 выражений — практическая учебная подборка, а не обещание точного рейтинга частотности. Маршрут 80/80/40 обозначает последовательность обучения и сложность контекста. В начале повторяются и базовые выражения. Термин «фразовые глаголы» используется в широком учебном смысле, включая некоторые предложные и трёхсловные сочетания.

После знакомства ответ скрыт: сначала попытка вспомнить, затем значение, пример, схема и объяснение. Интервалы 1/3/7/14/30/60 дней — прозрачное практическое правило. После затруднения выражение возвращается раньше. Дополнительный успешный повтор в тот же день не увеличивает интервал.

## Источники

Общие правила порядка слов: [British Council](https://learnenglish.britishcouncil.org/free-resources/grammar/b1-b2/phrasal-verbs) и [Cambridge English Grammar Today](https://dictionary.cambridge.org/grammar/british-grammar/verbs-multi-word-verbs). В карточках есть ссылки на словарь или общую грамматику. Объяснения, ассоциации и примеры написаны специально для приложения.

## Разработка

Статическое приложение без внешних runtime-зависимостей. GitHub Pages публикует `docs/` из `main`.

Локальный запуск: `python3 -m http.server 4178 --directory docs`.

Озвучка: инструкции в `scripts/AUDIO.md`. После изменения материалов обновите VERSION в `docs/offline.js` и `scripts/sw-template.js`, затем выполните `python3 scripts/build-offline.py`.
